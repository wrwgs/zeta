Pizza

I'm using the Pizza language for most of my current implementation work. Pizza is an add-on to Java, providing concepts a functional programmer is missing in Java: parameterized classes, free type constructions with pattern-based deconstruction, and anonymous methods.

Using Pizza in my daily work lead to the following by-products:

  • An aggregate library for Pizza, which provides immutable abstract Maps, Sets and Sequences
  • A XEmacs cc-mode style hook (version 1.5), which implements automatic indentation of Pizza 'fun's (as well as Java 1.1 array and class creator expressions).
