An Aggregate Library for Pizza

Version 0.5 (16.11.97)

A first attempt towards an aggregate library for Pizza. This library is a by-product of our work using Pizza/Java as a tool integration language for ESPRESS.

Remarks on the general design decisions are found here. Online documentation is found here.

Though the basic interfaces of the aggregate types should be complete (if you don't think so, please let us know!), not all intended implementation variants of aggregates are provided yet. The followings are definitely missing: 

   class OrdListSet<A implements Ordered<A>> extends Set<A>;
   class AvlSet<A implements Ordered<A>> extends Set<A>;
   class OrdListMap<A implements Ordered<A>,B> extends Map<A,B>;
   class AvlMap<A implements Ordered<A>,B> extends Map<A,B>;
The present implementations haven't been deeply tested; a beta-version can be obtained by contacting the authors. We are interested in feedback, and are open to suggestions for changes and extensions.
